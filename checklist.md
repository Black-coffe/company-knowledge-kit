# Чек-лист: база знаний компании

Шесть шагов из ролика, по порядку. Домашка охватывает первые три-четыре, остальные для тех, кто идёт дальше.

- [ ] 1. Выгрузить: папка документов лежит на диске, таблицы и PDF рядом в тексте
- [ ] 2. Аудит выгрузки: найдены секреты, персональные данные и файлы, открытые не тем, кому надо
- [ ] 3. Реестр: на каждый документ строка с владельцем, датой и статусом (`inventory-template.md`)
- [ ] 4. Правила старшинства: `conflict-rules.md` положены в `CLAUDE.md` базы
- [ ] 5. Саммари и темы: у каждого документа короткое саммари, вики собрана по темам
- [ ] 6. Замер: набор контрольных вопросов с ключом, прогон до и после, столбец «помогло / нет»
