# Комплект ролика 7: база знаний компании

Выдуманная компания Veltra Power: 77 документов, 14 противоречий. Всё выдумано, настоящих данных здесь нет.

Ролик: https://youtu.be/bi_R5IPNbLo · плейлист «Свои продукты с AI».

Проверено на Windows 11 (PowerShell, Claude Code). На Mac не проверялось.

## Что делать в домашке

Домашка не все шесть шагов ролика, а три действия: **выгрузи папку, запусти скилл, проверь список**. Остальные шаги (аудит, реестр, замер) в `checklist.md`, для тех, кто идёт дальше.

Нужен установленный Claude Code: в PowerShell `claude --version` должна ответить номером версии.

Скачай комплект: `git clone https://github.com/Black-coffe/company-knowledge-kit` или кнопка Code → Download ZIP на странице репозитория.

Дальше `$KIT` это путь к папке комплекта. Например: `$KIT = "C:\материалы\company-knowledge-kit"`.

### Шаг 1. Выгрузи папку

Создай пустую рабочую папку и положи в неё документы.

```powershell
mkdir C:\kb-hw\docs
```

Свои документы: скопируй одну свою папку в `C:\kb-hw\docs`. Таблицы Excel (*xlsx*), документы Word (*docx*) и PDF модель сама не читает, поэтому рядом с каждым положи текст: файл `price.xlsx` и рядом `price.xlsx.md` с его содержимым. Попроси Claude сделать такие тексты, а потом выбери и проверь глазами один-два.

Нет своих документов: возьми выдуманную компанию.

```powershell
Copy-Item -Recurse "$KIT\company\*" C:\kb-hw\docs
```

Мало времени: возьми маленький набор из 13 файлов вместо 77.

```powershell
Copy-Item -Recurse "$KIT\mini\*" C:\kb-hw\docs
```

### Шаг 2. Положи скилл

*Скилл* (skill) это папка с инструкцией для Claude Code. Он находит её сам, если она лежит в `.claude\skills` рабочей папки.

```powershell
mkdir C:\kb-hw\.claude\skills\find-conflicts
Copy-Item "$KIT\skill\SKILL.md","$KIT\conflict-rules.md" C:\kb-hw\.claude\skills\find-conflicts
```

### Шаг 3. Запусти и проверь список

```powershell
cd C:\kb-hw
claude
```

В открывшемся Claude Code набери: `Запусти скилл find-conflicts на папке docs`. Если Claude спросит разрешение читать файлы, разреши только чтение.

Ответ состоит из двух таблиц. Первая: два файла спорят. Вторая: копии одного файла и какая из них настоящая.

Проверь список: у каждой строки должно быть два файла и цитата из каждого. Любую цитату найди сам:

```powershell
Get-ChildItem C:\kb-hw\docs -Recurse -File | Select-String -SimpleMatch "цитата из таблицы"
```

Цитаты нет в файле: строка выдумана, вычеркни её. Строка без второго файла не противоречие, а одно утверждение.

Что ты должен увидеть на выдуманной компании: порог **9 из 12** противоречий (из 14 исключены два: «HX50» против «HX-50» и ссылка на удалённый файл). Копии прайса скилл показывает отдельной группой: четыре файла `price-list-2026h2.xlsx`, верный лежит в `commercial/prices/`. На мини-наборе: прайс в трёх копиях и одно обычное противоречие (например, кто подписывает договоры).

Скилл ошибается. Среди строк бывают лишние: файл не проверен, а его «статус» домыслен. Поэтому проверка цитат обязательна.

## Что дальше (необязательно)

Файлы комплекта:

| Файл | Зачем |
|---|---|
| `skill/SKILL.md` | скилл поиска противоречий: обычный проход и проход по копиям одного файла |
| `conflict-rules.md` | правила старшинства: чему верить, когда файлы спорят |
| `inventory-template.md` | шаблон реестра: строка на документ, владелец, дата, статус |
| `checklist.md` | шесть шагов ролика по порядку |
| `control-questions.md` | 40 контрольных вопросов к выдуманной компании с эталоном ответа, реестр прогонов |
| `company/` | выдуманная компания, 77 документов |
| `mini/` | 13 файлов для тех, у кого мало времени |

Набор контрольных вопросов к базе живой: после каждого изменения базы, правил или модели прогон повторяют, а вопросы людей добавляют в набор. Качество падает после обновлений, и это видно только на прогоне.

**Цена прогона.** Один прогон 40 вопросов по базе знаний: около 2,8 млн токенов (≈ $3,2 по API-ценам); три прогона для медианы: 8,4 млн токенов. Мы гоняли по подписке claude.ai, живых денег это не стоило; доллары это справочный эквивалент из ответов claude. Оба прогона (А и Б) шли параллельно около 35 минут.

**Результат замера.** Выдуманная компания · 77 документов · 14 противоречий · 40 вопросов · claude-sonnet-5-5, 2026-10-15, медиана трёх прогонов. А: сырые выгрузки. Б: те же файлы плюс `CLAUDE.md`, реестр и вики по темам.

| Показатель | А (сырое) | Б (база) |
|---|---|---|
| Верно из 40 | 30 | 38 |
| Верные со ссылкой, вопросы «один ответ» | 27 из 34 | 33 из 34 |
| «Два ответа, решает владелец» распознано | 1 из 3 | 2 из 3 |
| Честное «данных нет» | 2 из 3 | 3 из 3 |
| Вопросы, где документы спорят (18) | 13 из 18 | 16 из 18 |
| Прочие вопросы (22) | 17 из 22 | 22 из 22 |
| Выдумки за три прогона | 7 | 0 |

Б не идеальна: вопросы Q10 и Q35 неверны во всех трёх прогонах (на Q35 модель отвечает одним ответом, а не «два, решает владелец»). Набор вопросов после прогона не подкручивался. Судья: другая модель той же компании, порядок ответов перемешан, поэтому цифры стоит перепроверить своими вопросами.

Таблицы и PDF в текст до поиска: например, прайс `price-list-2026h2.xlsx` лежит рядом со своей выгрузкой `price-list-2026h2.xlsx.md`.
