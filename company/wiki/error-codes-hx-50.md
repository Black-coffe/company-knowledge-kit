# Коды ошибок HX-50

Последняя правка: 2024-08-27 · Mateo Silva (инженер поддержки)

| Код | Что значит | Что делать |
|---|---|---|
| E-03 | Напряжение сети вне допуска | Проверить сеть, инвертор перезапустится сам |
| E-05 | Сопротивление изоляции DC ниже нормы | Проверить кабели строк, вызвать монтажника |
| E-09 | Нет связи с модулем мониторинга | Перезапустить модуль связи |
| E-11 | Частота сети вне допуска | Ждать, инвертор перезапустится сам |
| E-14 | Ошибка датчика тока | Заявка в поддержку |
| E-17 | Перегрев | Проверить вентиляцию, перезагрузить инвертор |
| E-21 | Ошибка памяти | Обновить прошивку |

Если код повторяется больше трёх раз за сутки — заявка в поддержку.
