# Реестр документов: шаблон

Один документ, одна строка. Заполни по папке, которую выгрузил, и положи рядом с документами. Модель читает реестр первым: он говорит ей, чему верить.

Статус: `действует` / `устарело` / `черновик` / `копия`. Владелец: имя человека или роль; ушёл из компании, пиши `нет`. Круг доступа: кому можно видеть (`все`, `руководители`, `финансы`, `внешний`).

| Файл | Название | Владелец | Дата | Статус | Круг доступа | Заменяет / заменён | Заметка |
|---|---|---|---|---|---|---|---|
| `commercial/prices/price-list-2026h2.xlsx` | Прайс, второе полугодие 2026 | Sofia Marquez | 2026-07-01 | действует | руководители | заменяет `price-list-2026q1.xlsx` | пример строки; удали её |
|  |  |  |  |  |  |  |  |

Копии одного файла (`sales-danielle/price-list-2026h2.xlsx`) заводи отдельными строками со статусом `копия` или `черновик` и пиши в «Заметке», чем они отличаются от оригинала.
